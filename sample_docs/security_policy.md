# Security Policy
Employees must report suspected phishing emails to the Security Operations team using the approved reporting button in the mail client. Do not click links, open attachments, or reply to suspicious messages. If the reporting button is unavailable, forward the message as an attachment to the internal security mailbox specified by IT.
Access to company systems must use multi-factor authentication. Employees must not share passwords or authentication tokens. Sensitive documents should be stored only in approved company repositories.
Company confidential information must not be uploaded to public AI services unless approved by security and privacy teams. Access should follow least-privilege principles.
