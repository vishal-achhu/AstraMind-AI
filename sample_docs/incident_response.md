# Incident Response
When a security incident is identified, employees should report it immediately to the Security Operations team. Analysts record the time, affected systems, observed indicators, and reporter details in the incident management system.
The response team triages severity, preserves relevant evidence, contains affected systems where appropriate, investigates the root cause, and coordinates recovery. Actions that may destroy evidence should be avoided until the response lead approves them.
After closure, the incident owner documents impact, timeline, root cause, remediation, and lessons learned. High-severity incidents require a post-incident review.
